# 19 校準漂移的處理與可交易標的回測（2026-10-13）

> 程式：`reversal_v2/rolling.py`。結果：`research/results/v2_rolling/`。使用 18（嚴格標籤，2008–2023）與 17（樣本外 2024–26）已存的預測，不重新訓練。

## 1. 問題

17 發現模型輸出的機率尺度會隨時間漂移（MLP 驗證期平均 0.20 → 測試期 0.33），用驗證集分位數定的固定閾值因此失效：警報率從預期的 23% 變成 63%，每年誤報 115 天。

## 2. 滾動閾值

把閾值改成**模型自己最近 250 個交易日輸出的分位數**（分位數仍由驗證集基準率決定；驗證期輸出作為暖身；只用過去資料，每天更新）。這把「排序」和「尺度」分開：模型只需要排序正確，不需要尺度穩定。

| | 固定閾值 | 滾動 250 天 |
|---|---|---|
| **2008–2023（32 格）** | | |
| 警報率：各格平均 ± 標準差（GRU-hazard） | 0.30 ± 0.16（最高 0.63） | 0.25 ± 0.05（最高 0.33） |
| GRU-hazard 精確率 / 召回率 / 每年誤報 | 0.29 / 0.57 / 53 | 0.31 / 0.57 / 43 |
| ENS-hazard 精確率 / 召回率 / 每年誤報 | 0.30 / 0.62 / 48 | 0.30 / 0.58 / 41 |
| **2024–26 樣本外** | | |
| MLP-hazard 警報率 / 每年誤報 | 0.63 / 115 | 0.30 / 53 |
| ENS-hazard 警報率 / 每年誤報 | 0.54 / 96 | 0.32 / 54 |
| GRU-hazard 警報率 / 召回率 | 0.14 / 0.52 | 0.25 / 0.66 |

滾動閾值讓警報率穩定在設計值附近，精確率不降、誤報明顯減少；樣本外 GRU 原本「從不對漲勢發波峰警報」的問題也消失（警報率 0.14 → 0.25，召回率 0.52 → 0.66）。**這是實務上應採用的規則。**

## 3. 用 ETF 開盤價回測（SPY / QQQ / DIA / IWM）

`graded` 部位調整（13 §4.1），滾動閾值，隔日開盤成交、5 bp。Sharpe 相對 Buy & Hold 的差距：

| 2008–2023 | SPY | QQQ | DIA | IWM |
|---|---|---|---|---|
| GRU-hazard | −0.005 | −0.016 | −0.001 | −0.017 |
| MLP-hazard | −0.001 | +0.007 | +0.013 | −0.021 |
| ENS-hazard | +0.011 | −0.021 | −0.018 | −0.010 |
| logreg | −0.032 | −0.041 | −0.025 | −0.033 |

| 2024–26 樣本外 | SPY | QQQ | DIA | IWM |
|---|---|---|---|---|
| GRU-hazard | +0.004 | −0.006 | +0.019 | +0.001 |
| MLP-hazard | +0.019 | +0.056 | +0.168 | −0.043 |
| ENS-hazard | −0.013 | +0.016 | +0.116 | −0.113 |

- 換成真實可交易的 ETF 後，歷史上所有模型的差距都在 ±0.02 以內，等於沒有差別；樣本外互有正負。
- 這和 14 的結論一致：反轉訊號的交易價值集中在 2008–09，用指數價格與固定閾值時看起來的小幅優勢，換成 ETF 與穩定的閾值後消失。

## 4. 結論

- 校準漂移可以用滾動閾值解決，模型不需要重新校準；這讓警報系統在實務上可用（穩定的警報率、每年約 40 天誤報、抓到約 58% 的反轉）。
- 但作為擇時訊號，無論用指數或 ETF、固定或滾動閾值、歷史或樣本外，**都沒有穩定優於 Buy & Hold**。反轉機率的用途應該是風險監控（例如提高警覺、調整避險比例），而不是進出場。
